# Gimono Grace — Personal Website

A responsive, single-page personal portfolio website ready to publish with GitHub Pages.

## Files
- `index.html` — page content, SEO metadata and structured person data
- `styles.css` — responsive design and styling
- `script.js` — mobile navigation and current year footer

## Before publishing
1. Open `index.html` in a text editor.
2. Your email and three phone numbers have been added to the contact section. Review them before publishing because they will be public.
3. Replace `YOUR-GITHUB-USERNAME` in the canonical URL and JSON-LD URL with your GitHub username and chosen Pages URL.
4. Review all biography details and role descriptions for accuracy and update anything that has changed.
5. The portrait currently loads from the official Busitema University Senate page. If the university changes that image URL, the photo may stop appearing. You can instead download a portrait you have permission to use, put it in an `images` folder, and change the image `src` in `index.html` to `images/your-photo.jpg`.

## Publish using GitHub Pages
1. Sign in at https://github.com.
2. Create a new **public** repository. For a personal homepage, name it exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html`, `styles.css`, and `script.js` from this folder to the repository's root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish. Your website address will be `https://YOUR-GITHUB-USERNAME.github.io/`.

If you use a repository with a different name, the address will normally be `https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/`.
